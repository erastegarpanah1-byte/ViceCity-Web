# ViceCity-Web — آفتاب سرخ 🌴

یک بازی سه‌بعدی وبی اورجینال با حال‌وهوای شهر ساحلی استوایی؛ الهام‌گرفته از ژانر open-world action، بدون استفاده از نام، لوگو یا دارایی‌های GTA/Rockstar.

## اجرا
```bash
npm install
npm run dev
```
سپس `http://localhost:3000` را باز کن.

## کنترل‌ها
- `WASD` حرکت / رانندگی
- `F` ضربه
- کلیک چپ شلیک
- `E` تعامل و عبور از مرحله
- `V` تغییر حالت: پیاده، خودرو، قایق، هوا، سقوط آزاد
- `Shift` برای دویدن (ورودی آماده است)

## معماری
- `app/` — Next.js App Router و shell
- `components/game/` — رندر Three.js و HUD و شهر
- `game/core/` — زیرساخت رویداد و زمان
- `game/systems/` — سیستم‌های gameplay مستقل
- `game/state.ts` — state مرکزی با Zustand
- `data/` — داده‌های خودرو و مأموریت

## سیستم‌های فعلی
رندر سه‌بعدی procedural، شهر ساحلی، ساختمان‌های متنوع، نخل، آب، چرخه زمان، آب‌وهوا، HUD/minimap، wanted level شش‌مرحله‌ای، تعقیب پلیس، مبارزه، شلیک، رانندگی با سوخت، مأموریت چندمرحله‌ای، حالت‌های قایق/پرواز/سقوط آزاد، ماهیگیری، اقتصاد و ذخیره محلی.

## مسیر توسعه
این مخزن به‌صورت modular ساخته شده تا در commitهای بعدی بتوان مدل‌های low-poly، ترافیک هوشمند، انیمیشن شخصیت، سیستم cover، pathfinding، صدا، باران واقعی، آب فیزیکی و مأموریت‌های بیشتر را بدون تبدیل پروژه به یک فایل بزرگ اضافه کرد.
